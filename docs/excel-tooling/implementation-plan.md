# excel-tooling implementation plan

Build sequence for [design.md](design.md). The service reads a workbook through LibreOffice Calc and returns a [Table](../table.md).

The MVP is steps 1 through 7. It is done when a container is serving gRPC and the smoke client, pointed at `titles.xlsx`, gets back the two data rows from the Titles sheet: typed cells, the title row not included, the empty row skipped. `ReadTable` delivers those rows as a stream. Google Sheets, Yandex Tables, and extra format fixtures wait until that path is green.

Each step is one change. The tests named in the step land with it and stay green. Unit tests run on the host with pytest and do not start LibreOffice. Anything that calls UNO runs inside the image built in step 4, because `python3-uno` has to be the same interpreter as Calc.

Set **Status** to `not started`, `in progress`, or `done`.

Shared rules:

- Code lives in `modules/excel-tooling/`. Proto sources live in `proto/` so pdf-tooling can import the same table later.
- The internal model is plain data. Protobuf conversion happens at the gRPC boundary.
- A failure is an exception the server maps to a status. The scanner does not return a partial table.
- Header names are trimmed display text. Data cells are classified from the Calc type and the number format, not from that display text.

## Step 2. Columns and row scan

[Back to summary](#summary)

Done. `excel_id`, `header_candidates`, `columns_for_header`, and `data_rows` are in `columns.py` and `scan.py`. `pytest modules/excel-tooling/tests/test_columns.py modules/excel-tooling/tests/test_scan.py` passes on the host.

Pure functions over a `Grid`. No files, no Calc.

### Work

1. `columns.excel_id(index)` maps 0 to `A`, 25 to `Z`, 26 to `AA`, 27 to `AB`.

2. `scan.header_candidates(grid, k)` walks from row 1 through the used range.

   - A row is empty when it has no non-empty cell in the used column span.
   - A header cell uses the trimmed display string. After trim, an empty name does not become a column.
   - A row that yields no columns is not a candidate.
   - Empty rows between candidates do not consume a slot.
   - Stop after K candidates, or at the end of the used range.

3. `scan.columns_for_header(grid, excel_row)` returns the columns of that candidate. Two columns with the same trimmed name raise `DuplicateColumn`. A row that is not a current candidate raises `HeaderNotCandidate`. The caller passes the candidate list from the same grid and the same K.

4. `scan.data_rows(grid, header_row, columns)` starts on the next row. It emits a row when at least one header column is non-empty. Cells outside the header columns are ignored. An empty cell in a header column is omitted. Fifty consecutive non-emitted rows stop the walk. The used range stops it as well. `excel_row` on each emitted row is the sheet row.

`k` is already validated by the server. These functions receive 1 through 50.

## Step 3. Cell values

[Back to summary](#summary)

Done. `Reading` and `classify` are in `values.py`. `pytest modules/excel-tooling/tests/test_values.py` passes on the host.

`values.classify` turns one Calc reading into a `CellValue` or empty. The workbook step will pass it the readings. This step feeds it by hand.

A reading is: content kind (`empty`, `text`, `number`, `formula`, `error`), the displayed string, the numeric serial, the number-format flags, and the document null date (year, month, day).

### Work

Apply the first matching rule.

1. Content kind `empty`, or a formula whose displayed string is empty and whose error code is 0, is empty. A formula equal to 0 displays `0` and is not empty.
2. Content kind `error`, or a formula with a non-zero error code, is text. The text is the displayed token, such as `#N/A`.
3. Content kind `text` is text. Do not parse the string as a number.
4. Format flag `DATE`, `TIME`, or both (`DATETIME`) is a date. Add the truncated serial, as whole days, to the null date. The fraction of the serial is the time of day, rounded to the nearest second. `has_time` is set when the format includes `TIME`. A date-only format still returns the calendar day and leaves the clock at zero with `has_time` false. A time-only format still fills year, month, and day from the serial.
5. Format flag `LOGICAL` is bool. A zero serial is false. Any other serial is true.
6. Format flag `PERCENT` or `CURRENCY` is float, the serial itself.
7. Any other number whose distance to the nearest integer is under `1e-9`, and that integer fits in `int64`, is int.
8. Any other number is float.

Take the flag names from `com.sun.star.util.NumberFormat` in the workbook step. This function receives booleans (`is_date`, `is_time`, `is_logical`, `is_percent`, `is_currency`) so the unit test does not import UNO.

The null date is an input. The default Calc epoch is 1899-12-30, which already matches Excel's 1900 system, including the historical serial gap. A 1904 workbook passes null date 1904-01-01. The classifier does not guess which epoch it is looking at.

## Step 5. gRPC sessions

[Back to summary](#summary)

Done. `ExcelToolingService` serves the five RPCs, and `__main__.py` listens on `0.0.0.0:50051`. Host `pytest tests/test_session.py -m "not libreoffice"` passes. `titles_over_grpc` and `lingerie_over_grpc` pass inside the image.

The five RPCs from [design.md](design.md). Unit tests drive them with a fake workbook that returns grids. Integration tests in the image use `titles.xlsx` and `JPGVL0I5VW.xlsm`.

### Work

1. Session map keyed by a new UUID. Each session holds the temp file path, the open document, the selected sheet index, the candidate limit, the current candidates, and the selected header row if any. Idle time is 15 minutes from the last call. A call that finds an expired session deletes it and returns `NOT_FOUND`. `Close` deletes it immediately.

2. One lock covers UNO calls and the session map. A second RPC waits. Do not open two documents on the listener at once.

3. `OpenWorkbook` is client streaming. The first message is `OpenMeta`. Later messages are bytes. Write them to a temp file named with the lowercased extension. Extensions `xlsx`, `xlsm`, `xls`, `ods` are accepted. Anything else, including `csv`, is `INVALID_ARGUMENT` and the file is removed. `header_candidate_limit` of 0 means 10. A value above 50 is `INVALID_ARGUMENT`.

   On success the reply is the non-empty sheets, the first of those selected, and that sheet's candidates. `NoData` is `FAILED_PRECONDITION`. A Calc failure is `INTERNAL`.

4. `SelectSheet` requires a listed sheet index. It replaces the candidates and clears a previously selected header. Unknown session is `NOT_FOUND`. An index that is not in the non-empty list is `FAILED_PRECONDITION`.

5. `SelectHeader` requires `excel_row` to be one of the current candidates. `subcolumn_row` of 0 means none. A non-zero value must be one of the four rows after that column row and must exist on the sheet. The reply is a `Table` with columns set and no rows. When a subcolumn row is set, a parent column lists the subcolumn labels in its span. `DuplicateColumn`, `HeaderNotCandidate`, and `SubcolumnRowOutOfRange` are `INVALID_ARGUMENT`.

6. `ReadTable` requires a header already selected. The reply is those columns plus `data_rows`. If a subcolumn row was selected, the walk starts after that row and reads leaf columns. Calling it earlier is `FAILED_PRECONDITION`.

7. Map the internal model to the generated messages at this boundary. Column order is the list order. Omitted cells are absent from `Row.cells`.

8. Set the server max receive size to 64 MiB.

`__main__.py` listens on `0.0.0.0:50051` but is not the compose entry yet. Tests start the server on an ephemeral port in-process.

## Step 6. Streamed read

[Back to summary](#summary)

Done. `ReadTable` returns `stream RowBatch`. Opening a workbook lists a sheet from its used area and reads header candidates one row at a time until K is reached. The data walk reads at most 2,000 sheet rows, drops that block, then reads the next. The RPC sends at most 100 processed rows per message. Host `pytest -m "not libreoffice"` passes. `titles_stream` and `lingerie_stream` pass inside the image.

### Work

1. In `excel.proto`, `ReadTable` returns `stream RowBatch`. `RowBatch` is a repeated `Row` and has no columns. Regenerate the stubs with `scripts/gen_proto.sh`. `SelectHeader` stays a unary `Table` of column names.

2. Stop building a full `Grid` for every non-empty sheet during `open`. Listing a sheet only needs to know that one cell is non-empty. Header candidates read only until K non-empty rows are found.

3. The data walk reads the used column span, 2,000 sheet rows at a time, starting on the row after the header. A sheet shorter than 2,000 rows is one read. Classify that block, yield its processed rows, and drop the block before the next `getDataArray`. Do not keep a second block. Do not start the next read while the current block is still held. Empty rows in the block count toward the 50-row stop and are not yielded. The stop, or the end of the used area, ends the walk.

4. `ReadTable` is server streaming. It takes processed rows from that walk and writes a `RowBatch` whenever it has 100, and a shorter batch at the end. After a batch is written, those rows are not kept. `ReadTable` before `SelectHeader` is still `FAILED_PRECONDITION`. A failure while a block is being read fails the RPC. The client must not treat the batches already received as a complete table.

5. Update the step 5 tests that call unary `ReadTable`. They concatenate the stream and keep the same assertions. `titles_over_grpc` is one short batch. `lingerie_over_grpc` is 2,924 data rows in batches of 100, and one shorter last batch.

|---|---|
